## Session Start Protocol

**Before touching any file, every session:**

1. Read `docs/SPEC.md` — what does this product do?
2. Read `docs/ARCHITECTURE.md` — how is it built?
3. Read `docs/DECISIONS.md` — why were decisions made?
4. Read `.mdd/docs/<feature>.md` if working on a specific feature
5. `git log --oneline -20` — what changed recently?
6. `git status` — what's currently dirty?

**Only then write code.**
