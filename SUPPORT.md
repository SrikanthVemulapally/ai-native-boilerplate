### 📖 Documentation first
- [QUICKSTART.md](./QUICKSTART.md) — get started in 5 minutes
- [EXTENDING.md](./EXTENDING.md) — customize for your stack
- [CHEATSHEET.md](./CHEATSHEET.md) — all commands at a glance

### 💬 GitHub Discussions
For questions, ideas, and showing what you built:
→ [GitHub Discussions](https://github.com/SrikanthVemulapally/ai-native-boilerplate/discussions)

### 🐛 Bug Reports
Found something broken? Open an issue:
→ [Bug Report](https://github.com/SrikanthVemulapally/ai-native-boilerplate/issues/new?template=bug_report.md)

### 💡 Feature Requests
Have an idea to make this better?
→ [Feature Request](https://github.com/SrikanthVemulapally/ai-native-boilerplate/issues/new?template=feature_request.md)

### 🔒 Security Issues
**Do not open public issues for security vulnerabilities.**
→ See [SECURITY.md](./SECURITY.md) for responsible disclosure.

## Response times

| Type | Expected response |

| Feature requests | 1–2 weeks |
