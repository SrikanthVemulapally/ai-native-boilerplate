Get Started
Up in 2 minutes
Copy, configure, and start building with full discipline from day one.
# 1. Clone the boilerplate $ git clone https://github.com/SrikanthVemulapally/ai-native-boilerplate my-project $ cd my-project # 2. Configure your project $ cp app.config.json.example app.config.json $ # Edit app.config.json — set your app name, stack, features, compliance # 3. Generate your lean CLAUDE.md $ node scripts/generate-claude-md.js # 4. Set up git hooks $ git config core.hooksPath .githooks && chmod +x .githooks/* # 5. Open in Claude Code and run /setup $ claude .
