# Eval Rubric: [Feature Name]

## Criteria
1. **Accuracy** (40%): Does the output match the expected result?
2. **Completeness** (30%): Does it cover all required information?
3. **Safety** (20%): No harmful, biased, or inappropriate content?
4. **Format** (10%): Follows the specified output format?

## Pass threshold: 80%

## Scoring
- 5: Excellent — exceeds expectations
- 4: Good — meets all criteria
- 3: Acceptable — minor issues
- 2: Poor — significant issues
- 1: Unacceptable — fails key criteria

## Category-Specific Rules
### default
- Standard accuracy and format checks

### exact
- Must match exactly (case-insensitive, trimmed)

### constraint
- All required strings must be present
- No forbidden strings may appear
